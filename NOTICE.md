# VinaKey: provenance and license notices

VinaKey is a modified distribution of [OpenKey](https://github.com/tuyenvm/OpenKey), originally created by Mai Vũ Tuyên (Tuyen Mai) with community contributions. Original source copyright notices are preserved. The inherited code and this derivative are distributed under the GNU General Public License, version 3; see [LICENSE](LICENSE).

Vina Design Store's modifications include the macOS Rust engine port and native bridge, input lifecycle fixes, simplified settings and menu UI, per-application language rules, VinaKey branding and independent macOS bundle identity. The source history records authorship and modification dates. Windows/Linux source remains inherited OpenKey code.

The VinaKey name identifies this modified project; it does not imply an official OpenKey release or endorsement by the upstream authors.
